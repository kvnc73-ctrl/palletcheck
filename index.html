SYSTEM DOCS
📋 Workflow
  1. Pick. Consolidate items onto "To Pallet" — the outbound unit.
  2. Stage. Pallets staged at trailer door.
  3. Configure. Loader opens app, sets Door + Trailer + SO + Shift.
  4. Scan. Each barcode validated: SO → ToPallet membership.
  5. Resolve. Wrong-SO / unknown / duplicate scans blocked & logged.
  6. Confirm. Button unlocks only at 100% loaded.
  7. Seal. Record auto-saved to Master Data.
⚠ Validation Rules
Accept — pallet in SO manifest, not yet scanned.
Reject — Wrong SO — pallet belongs to a different order.
Reject — Duplicate — already scanned this session.
Reject — Unknown — not in any pallet registry.
🗄 Data Sources

Sales Order History CSV (riteSCAN) — Columns: Date, User, Sales Order, Stock Code, Lot, Quantity, From Bin, From Pallet, To Pallet. To Pallet = pallet ID scanned; Stock Code = SKU. Supports pallet mix: same pallet ID with multiple SKUs (each row preserved). Upload via Admin panel to refresh embedded DB.
Dock Activity Report XLSX (Blujet) — Used to populate loader list and open orders. Upload alongside Sales Order History in Admin panel.
Loaders — Sourced from CSV user field, searchable, add/delete, persistent via localStorage.
Master Data — Stored in localStorage, survives browser restarts, exportable to Excel any time.

⚡ Power Automate Integration

On Confirm Load, the app sends a JSON payload to a Power Automate HTTP trigger. Flow structure:
  1. HTTP Trigger — Receives JSON body with door, trailer, so, shift, loader, total, wrongScans, startTime, pallets[]
  2. Add row → Load Summary table — Top-level fields (door, trailer, SO, etc.)
  3. Apply to each triggerBody()?['pallets'] → Add row → Pallet Detail table — Per-pallet: id, sku, qty, lot, scannedAt
JSON Schema in trigger must declare pallets as array type or Apply to each fails with pallets is Null. Use Expression (not blue token) for items('Apply_to_each')?['scannedAt'] in Pallet Detail.

🔁 Confirm Load Flow

1. Scan all pallets until 100% → Confirm Load button activates.
2. Tap Confirm Load → confirmation modal appears.
3. Tap OK — Confirm & Save → doConfirm() runs:
  • Saves record to Master Data (localStorage)
  • Triggers Power Automate HTTP call with full pallet payload
  • Resets all fields and returns to New Trailer Load setup screen
